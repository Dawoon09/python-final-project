## 1. 개요

「제자 키우기」는 플레이어가 교수가 되어 신입생 한 명을 4분 동안 돌보며 졸업까지 키우는 pygame 육성 게임이다. 그래픽 리소스 없이 원, 사각형, 선만으로 모든 화면을 그린다.

| 항목 | 내용 |
|---|---|
| 게임명 | 제자 키우기 |
| 장르 | 육성 시뮬레이션 (다마고치형) |
| 플레이 시간 | 1판 약 4분 (1학년~4학년, 학년당 60초) |
| 작성자 | AI융합소프트웨어학과 조다운 |
| 개발 기간 | 1주 (7일), 1인 개발 |

**기획 의도:** 공부만 시키면 제자가 지쳐 쓰러지고, 쉬게만 하면 졸업 성적이 낮아진다. 체력, 멘탈, 지식 사이에서 균형을 잡는 것이 이 게임의 핵심 재미다. 대학 생활을 소재로 삼아, 플레이하는 사람이 자기 학교 생활을 떠올리며 웃을 수 있게 하는 것이 목표다.

## 2. 게임 규칙

제자를 240초(4학년) 동안 휴학시키지 않고 버티게 하면 졸업하며, 그동안 쌓은 지식에 따라 엔딩이 달라진다. 아래 수치는 초기값이며, 6일차 밸런스 테스트에서 조정한다.

### 게이지

| 게이지 | 범위 | 시작값 | 자연 감소 | 0이 되면 |
|---|---|---|---|---|
| 체력 | 0~100 | 80 | 1초마다 -1 | 휴학 엔딩 |
| 멘탈 | 0~100 | 80 | 1초마다 -1 (시험 기간 -2) | 휴학 엔딩 |
| 지식 | 0 이상, 상한 없음 | 0 | 없음 | (엔딩 등급 기준) |

### 행동 (세 행동은 쿨타임 1초를 공유해 연타를 막는다)

| 행동 | 체력 | 멘탈 | 지식 |
|---|---|---|---|
| 학식 먹이기 | +20 | - | - |
| 쉬게 하기 | - | +20 | -2 |
| 공부시키기 | -5 | -8 | +10 (시험 기간 +20) |

### 진행

- **학년 진급:** 60초마다 자동으로 1학년 → 2학년 → 3학년 → 4학년으로 올라가고, 학년이 오를 때마다 캐릭터가 커진다.
- **시험 기간:** 각 학년의 마지막 15초다. 공부 효과가 2배가 되지만 멘탈도 2배로 줄어든다.
- **휴학 엔딩:** 체력이나 멘탈 중 하나라도 0이 되면 그 즉시 게임이 끝난다.
- **졸업 엔딩:** 240초를 버티면 누적 지식에 따라 세 가지 중 하나가 나온다.

| 엔딩 | 조건 (누적 지식) |
|---|---|
| 수석 졸업 | 500 이상 |
| 무사 졸업 | 300~499 |
| 아슬아슬 졸업 | 300 미만 |

## 3. 조작 방법

모든 행동은 마우스 클릭과 키보드 단축키 둘 다로 할 수 있다.

| 조작 | 마우스 | 키보드 |
|---|---|---|
| 학식 먹이기 | [학식] 버튼 클릭 | 1 |
| 쉬게 하기 | [휴식] 버튼 클릭 | 2 |
| 공부시키기 | [공부] 버튼 클릭 | 3 |
| 게임 시작 | - | Enter (타이틀 화면) |
| 다시 하기 | - | R (엔딩 화면) |
| 게임 종료 | 창 닫기 버튼 | ESC |

## 4. 화면 구성

화면은 타이틀, 게임, 엔딩 3개로 구성하며, 창 크기는 800×600이다. 모든 그림은 pygame.draw의 원, 사각형, 선, 호로 그린다.

| 화면 | 표시 내용 |
|---|---|
| 타이틀 | 게임 제목, 최고 기록, "Enter를 눌러 시작" 안내 |
| 게임 | 상단 정보바, 시험 기간 배너, 게이지, 제자 캐릭터, 행동 버튼 3개 (아래 그림) |
| 엔딩 | 엔딩 이름(휴학 / 수석 / 무사 / 아슬아슬 졸업), 누적 지식, 졸업 시 학사모, "R을 눌러 다시 하기" 안내 |

### 게임 화면 배치 (800×600 창)

게임 화면은 정보, 게이지, 제자, 버튼 네 구역으로 나뉜다.

```
┌──────────────────────────────────────────────────────────┐
│ 2학년              남은 시간 38초                지식 120 │  ← 상단 정보바
├──────────────────────────────────────────────────────────┤
│        시험 기간! 공부 효과 2배, 멘탈 감소 2배            │  ← 시험 기간 배너(노란색)
├────────────────────┬─────────────────────────────────────┤
│ 체력               │                                     │
│ [■■■■■■■■□□□]      │            (  ●─●  )                │
│ 멘탈               │            (   ︵   )                │  ← 제자(원), 안경, 표정
│ [■■□□□□□□□□□]      │                                     │
│ 30 미만이면 빨간색 │  제자: 학년마다 커지고, 3학년부터 안경 │
├────────────────────┴─────────────────────────────────────┤
│ [ 학식 먹이기 [1] ]  [ 쉬게 하기 [2] ]  [ 공부시키기 [3] ] │  ← 행동 버튼 3개
│             누른 뒤 1초 동안 회색 (쿨타임)                │
└──────────────────────────────────────────────────────────┘
```

- 그림 속 예시: 체력 막대는 초록색, 멘탈 막대는 30 미만이라 빨간색이다.

제자의 표정은 멘탈이 60 이상이면 웃는 입, 30~59면 일자 입, 30 미만이면 우는 입이다. 캐릭터 반지름은 1학년 40에서 학년마다 10씩 커져 4학년에 70이 된다.

## 5. 기능 목록

총 13개 기능을 구현하며, 1~10번은 필수 기능, 11~13번은 추가 기능이다.

### 필수 기능

1. 학식 먹이기 ([학식] 버튼 클릭 또는 1키): 체력 +20
2. 쉬게 하기 ([휴식] 버튼 클릭 또는 2키): 멘탈 +20, 지식 -2
3. 공부시키기 ([공부] 버튼 클릭 또는 3키): 지식 +10, 체력 -5, 멘탈 -8
4. 행동 쿨타임 (자동): 행동 후 1초간 버튼이 회색으로 변하고 입력을 받지 않음
5. 게이지 자연 감소 (자동): 1초마다 체력·멘탈 -1
6. 게이지 막대 표시 (자동): 체력·멘탈은 막대로, 30 미만이면 빨간색 / 지식은 숫자로 표시
7. 표정 변화 (자동): 멘탈에 따라 입 모양, 체력 30 미만이면 다크서클
8. 학년 진급과 캐릭터 성장 (자동): 60초마다 학년이 오르고 캐릭터 크기 증가, 3학년부터 안경
9. 휴학 엔딩 (자동): 체력 또는 멘탈이 0이 되면 엔딩 화면으로 전환
10. 화면 전환 (Enter / R / ESC): 타이틀 → 게임 → 엔딩, 다시 하기, 종료

### 추가 기능

11. 시험 기간 이벤트 (자동): 각 학년 마지막 15초 동안 상단에 "시험 기간" 배너, 공부 효과 2배, 멘탈 감소 2배
12. 졸업 엔딩 3종 (자동): 240초 생존 시 누적 지식으로 수석 / 무사 / 아슬아슬 졸업 판정, 학사모 표시
13. 최고 기록 저장 (자동): 게임이 끝날 때 최고 누적 지식을 record.json에 저장하고 타이틀 화면에 표시

## 8. 화면 연출 (추가)

> 2026-11-18 추가. 1차 완성 후 "그래픽이 밋밋하고 상호작용이 투박하다"는 피드백을 반영한다. 게임 규칙과 수치(2~5절)는 바꾸지 않고 보이는 방식만 바꾼다.

### 도트 그래픽

- 이미지 파일 없이 `pygame.draw`로 작은 사각형(4×4 픽셀)을 찍어 도트 그래픽을 그린다.
- 파스텔 레트로 팔레트(크림 배경, 진한 남색 외곽선, 민트·하늘·살구·연분홍·노랑)를 쓴다.
- 버튼·게이지·배너·정보바는 모서리가 계단처럼 깎인 도트 사각형으로 그린다.
- 제자는 도트 스프라이트로 그리며, 학년별 크기(반지름 40/50/60/70)와 표정·다크서클·안경 규칙은 그대로다.
- 게이지 30 미만 빨간색, 쿨타임 중 회색 버튼 규칙도 그대로다.

### 상호작용 효과

| 효과 | 내용 |
|---|---|
| 버튼 호버·눌림 | 마우스를 올리면 버튼이 밝아지고, 누르면 살짝 눌렸다 올라온다. 쿨타임 동안에는 회색 버튼 위로 1초짜리 진행 막대가 찬다 |
| 행동별 파티클 | 학식은 하트·밥알, 휴식은 Zzz·구름, 공부는 별·연필 모양 도트가 제자 주변에서 터져 나온다 |
| 수치 팝업 | "체력 +20", "지식 +10"처럼 실제로 바뀐 양이 글자로 떠올랐다 사라진다 |
| 부드러운 게이지 | 게이지 막대가 한 번에 바뀌지 않고 0.25초 동안 부드럽게 늘거나 줄어든다 |
| 제자 반응 | 행동할 때 제자가 통통 튀고, 평소에는 숨 쉬듯 살짝 위아래로 움직인다 |
| 안내 깜빡임 | 타이틀·엔딩의 키 안내 문구가 깜빡인다 |

## 9. 랜덤 이벤트와 성장 (추가)

> 2026-11-19 추가. 매 판이 다르게 흘러가도록 랜덤 이벤트를, 선택의 결과가 남도록 특성·외형·연계 이벤트를 넣는다. 2~5절의 기본 규칙(게이지, 행동, 학년, 시험 기간, 엔딩 기준 500/300)은 그대로다.

### 발생 규칙

- 행동(학식·휴식·공부)이 **실제로 실행된 직후** 25% 확률로 이벤트가 뜬다. 쿨타임 때문에 무시된 입력, 그 행동으로 휴학하는 경우에는 뜨지 않는다.
- **최소 보장:** 학년마다 학년 안 0~45초를 11.25초씩 4구간으로 나눈다. 구간 k(1~4)가 끝난 뒤(학년 안 경과 ≥ 11.25×k초) 그 학년 이벤트 수가 k보다 적으면, 다음 행동 때 확률과 상관없이 이벤트가 뜬다. 그래서 행동을 꾸준히 하면 학년당 최소 4회가 된다.
- **최대:** 학년당 5회.
- **선택지형(큰 사건):** 게임이 멈춘다(경과 시간·게이지·쿨타임 정지). 대화창의 선택지 2개 중 하나를 키 1·2 또는 클릭으로 고르면 결과가 적용되고 게임이 다시 흐른다. 대화창이 떠 있는 동안 행동 버튼과 행동 키는 동작하지 않는다(ESC 종료는 가능).
- **자동형(작은 사건):** 게임은 멈추지 않는다. 무대 위에 2초 동안 알림 배너가 뜨고 효과가 바로 적용된다.
- 이벤트 효과로 게이지가 바뀔 때도 0~100 범위와 지식 0 이상 규칙을 지키고, 체력·멘탈이 0이 되면 즉시 휴학 엔딩이다.
- 같은 선택지형 이벤트는 한 판에 한 번만 나온다. 자동형은 반복될 수 있다.
- 뽑기 순서: 그 학년에 나올 수 있는 선택지형(학년 조건·연계 조건을 만족하고 아직 안 나온 것)과 자동형을 모은 후보에서 하나를 고른다. 선택지형 후보가 있으면 50%는 선택지형, 50%는 자동형이다.

### 이벤트 목록

**자동형 (모든 학년)**

| 이벤트 | 효과 |
|---|---|
| 엄마가 반찬을 보내셨다 | 체력 +15 |
| 단톡방에서 칭찬받았다 | 멘탈 +10 |
| 과제 마감 알림이 울렸다 | 멘탈 -10 |
| 감기 기운이 돈다 | 체력 -10 |
| 교수님께 칭찬받았다 | 지식 +15, 멘탈 +5 |

**선택지형**

| 학년 | 이벤트 | 선택 1 | 선택 2 |
|---|---|---|---|
| 1 | MT 초대 | 간다: 멘탈 +15, 체력 -10, 연계 "MT 참석" | 공부한다: 지식 +10, 멘탈 -5 |
| 1 | 동아리 박람회 | 밴드부: 외형 기타, 특성 음악 힐링, 연계 "밴드부" | 헬스부: 외형 머리띠, 특성 체력 단련 |
| 2 | 조별과제 무임승차자 | 혼자 다 한다: 지식 +20, 체력 -15, 멘탈 -10 | 교수님께 말한다: 멘탈 +5 |
| 2 | 밤샘의 유혹 | 커피로 버틴다: 지식 +10, 외형 커피잔, 특성 카페인 | 그냥 잔다: 체력 +10 |
| 3 | 고백을 받았다 | 사귄다: 멘탈 +15, 외형 하트 머리핀, 특성 연애 중, 연계 "연애 중" | 공부에 집중: 지식 +20, 멘탈 -10 |
| 3 | 교환학생 공고 | 지원한다: 지식 +25, 체력 -10 | 다음에: 멘탈 +5 |
| 4 | 취업 박람회 | 대기업 지원: 지식 +20, 멘탈 -15 | 대학원 상담: 지식 +10, 멘탈 +5 |
| 2~4 | (연계: MT 참석) 선배가 족보를 준다 | 받는다: 지식 +15 | 거절한다: 멘탈 +5 |
| 3~4 | (연계: 밴드부) 축제 무대 제안 | 무대에 선다: 멘탈 +25, 체력 -10, 외형 선글라스 | 연습만 한다: 멘탈 +5 |
| 4 | (연계: 연애 중) 졸업 전 데이트 | 데이트한다: 멘탈 +20, 체력 -5 | 도서관에 간다: 지식 +15 |

"학년"은 그 학년 이상에서 나올 수 있다는 뜻이 아니라 표에 적힌 학년에서만 나온다(2~4는 2·3·4학년 모두 가능).

### 성장 요소

**특성** (얻으면 그 판 끝까지 유지, 새 판에서 초기화)

| 특성 | 효과 |
|---|---|
| 체력 단련 | 학식 먹이기 체력 +20 → +25 |
| 음악 힐링 | 쉬게 하기 멘탈 +20 → +25 |
| 카페인 | 공부시키기 체력 -5 → -3 |
| 연애 중 | 쉬게 하기에 체력 +5가 함께 붙음 |

**외형:** 기타(등 뒤), 헬스 머리띠, 커피잔(손), 하트 머리핀, 선글라스(머리 위). 얻으면 그 판 끝까지 제자에게 도트로 붙어 있다. 안경(3학년~)·다크서클·표정과 함께 보여야 한다.

**화면:** 상태 패널 아래쪽에 얻은 특성 이름을 작은 배지로 표시한다. 엔딩 화면과 졸업 등급 판정은 바뀌지 않는다.
