# 제자 키우기 게임 기획서

Nov 23, 2026 · @조다운

> 처음 기획서는 `제자 키우기 게임 기획서.pdf`(5쪽, 2026-11-18)다. 그때는 240초 동안 버튼을 눌러 돌보는 게임이었다. 이 문서는 그 뒤에 더한 연출·이벤트·방치형·시간 제한 제거를 모두 반영한 **최종 게임** 기준이다. 무엇이 언제 바뀌었는지는 맨 아래 "부록: 변경 이력"에 적었다. 모든 수치는 `config.py`와 같다.

## 1. 개요

「제자 키우기」는 플레이어가 교수가 되어 신입생 제자 한 명을 졸업까지 키우는 pygame 방치형 육성 게임이다. 제자는 스스로 밥을 먹고, 쉬고, 공부한다. 플레이어는 일과표 방침을 정하고, 제자가 공부로 번 연구비로 업그레이드를 산다. 이미지·사운드 파일 없이 `pygame.draw`의 도형만으로 모든 화면을 그린다.

| 항목 | 내용 |
|---|---|
| 게임명 | 제자 키우기 |
| 장르 | 방치형 육성 시뮬레이션 |
| 플레이 방식 | 제자가 2초마다 스스로 행동한다. 플레이어는 방침(공부 위주 / 균형 / 휴식 위주)과 업그레이드를 고른다 |
| 시간 감각 | 판에 시간 제한이 없다. 업그레이드 없는 첫 판은 졸업까지 약 6~11분(10절), 업그레이드를 모을수록 빨라진다. 대학원은 체력·멘탈이 버티는 동안 끝없이 이어진다 |
| 창 크기 | 800×600 |
| 작성자 | AI융합소프트웨어학과 조다운 |
| 개발 기간 | 2026-11-18 ~ 2026-11-23, 1인 개발 |

**기획 의도:** 공부만 시키면 제자가 지쳐 쓰러지고(지치면 공부·연구비 효율도 떨어진다), 쉬게만 하면 졸업이 늦어진다. 버튼을 연타하는 대신 "어떤 방침으로 키울지"와 "연구비를 어디에 쓸지"를 고르는 것이 이 게임의 핵심 재미다. 한 판이 끝나도 업그레이드와 명성이 남아서, 다음 제자는 더 빨리 졸업한다. 대학 생활을 소재로 삼아, 플레이하는 사람이 자기 학교 생활을 떠올리며 웃을 수 있게 하는 것이 목표다.

## 2. 게임 규칙

제자를 휴학시키지 않고 누적 지식을 모아 졸업시키면 된다. 학년은 시간이 아니라 **누적 지식(학점)**으로 오르고, 졸업 등급은 **졸업까지 걸린 시간**으로 정한다.

### 게이지

| 게이지 | 범위 | 시작값 | 자연 감소 | 0이 되면 |
|---|---|---|---|---|
| 체력 | 0~최댓값 (기본 100) | 80 | 1초마다 -1 (든든함이면 -0.5) | 휴학 엔딩 (대학원이면 수료) |
| 멘탈 | 0~최댓값 (기본 100) | 80 | 1초마다 -1 (시험 기간 -2, 개운함이면 ×0.5) | 휴학 엔딩 (대학원이면 수료) |
| 지식 | 0 이상, 상한 없음 | 0 | 없음 | (진급·졸업 기준) |

- **최댓값:** 기본 100. 체력 증진 업그레이드로 체력 최대, 멘탈 관리 업그레이드로 멘탈 최대가 레벨마다 +10 오른다(3절, 최대 150). 시작값은 최댓값과 상관없이 80이다.
- 체력·멘탈은 어떤 경우에도 0~최댓값을 벗어나지 않는다. 지식은 0 아래로 내려가지 않는다.
- **회복은 휴식에서만** 된다. 학식은 게이지를 바로 올리지 않고 버프 '든든함'을 준다. 예외: 랜덤 이벤트(4절)는 예전처럼 게이지를 바로 바꾼다.
- 자연 감소는 게임 시간 1초마다 한 번 일어난다. 프레임 속도와 상관없다.
- 건강 관리 업그레이드를 사면 자연 감소가 ×(1 − 0.1 × 레벨)이 된다(5레벨이면 ×0.5). 대학원에서는 여기에 대학원 배수를 더 곱한다(3절). 든든함이면 체력 감소에 ×0.5를 더 곱한다.
- 자기 관리 업그레이드를 사면 자연 감소와 같은 1초마다 체력·멘탈이 각각 +0.2 × 레벨 오른다. 무엇을 하든(휴식 중에도) 늘 더한다. 한 번에 "회복 − 감소"를 적용한다.
- 그래서 체력·멘탈은 소수가 될 수 있다(소수 6자리에서 반올림). 막대는 소수 값 그대로 그리고, 수치 팝업과 "지금/최대" 글자는 반올림한 정수로 보인다.
- 0이 되는 순간(0 이하) 바로 엔딩이다. 자연 감소, 공부, 이벤트 무엇으로 0이 되어도 같다.

### 자동 행동과 일과표 방침

- 게임 화면에서 제자는 **2초마다** 행동 하나를 스스로 고른다. 게임을 시작하고 첫 행동도 2초 뒤다. 시간 관리 업그레이드로 간격이 레벨마다 0.2초씩 줄어든다(2.0 → 1.0).
- 고르는 순서:
  1. 체력이나 멘탈이 방침의 **회복 기준 미만**이면 **휴식**한다.
  2. 아니고 버프 **든든함이 없으면 학식**을 먹는다.
  3. 둘 다 아니면 **공부**한다.
- 방침은 키 1·2·3 또는 방침 버튼으로 언제든 바꾼다. 다음 자동 행동부터 새 방침을 따른다. 고른 방침 버튼은 노란색으로 강조된다.

| 방침 | 키 | 회복 기준 | 공부 지식 | 공부 체력·멘탈 소모 | 휴식 회복 | 그 밖에 |
|---|---|---|---|---|---|---|
| 공부 위주 | 1 | 25 | ×1.8 | ×1.8 | ×1.0 | - |
| 균형 | 2 | 50 | ×1.0 | ×1.0 | ×1.0 | - |
| 휴식 위주 | 3 | 70 | ×0.7 | ×0.7 | ×1.5 | 컨디션 좋음: 체력·멘탈이 둘 다 70 이상이면 연구비 +50% |

- 방침은 **새 판마다 균형으로 돌아간다**(타이틀에서 시작, 휴학 뒤 다시 하기, 환생). 대학원 진학은 같은 판을 이어 가므로 방침이 그대로다.
- 선택지형 이벤트 대화창이 떠 있는 동안에는 자동 행동 시계도 멈춘다.
- 다음 자동 행동까지 남은 시간은 방침 버튼 아래 진행 막대로 보인다.

### 행동 효과

학식 먹이기는 게이지를 바꾸지 않고 버프 든든함만 준다. 쉬게 하기는 회복과 함께 버프 개운함(20초)을 준다. 쉬게 하기·공부시키기는 아래 기본값에 특성(4절)과 업그레이드(3절)가 더해진다.

| 효과 | 기본 | 더해지는 것 |
|---|---|---|
| 학식 든든함 지속 | 30초 | 체력 단련 +10초, 자취 요리 +5초, 학식 메뉴 개선 +6초/Lv |
| 휴식 체력 | +15 | 연애 중 +5, 아침형 인간 +3, 카페 +5, 푹신한 침대 +4/Lv |
| 휴식 멘탈 | +20 | 음악 힐링 +5, 아침형 인간 +3, 푹신한 침대 +4/Lv |
| 휴식 지식 | -2 | - |
| 공부 지식 | +10 (시험 기간 +20) | 스터디 그룹 +2, 참고서 +2/Lv, 도서관 +3 |
| 공부 체력 | -5 | 카페인 +2, 헬스장 +2 |
| 공부 멘탈 | -8 | 명상 +2 |

- **공부 계산 순서:** 기본값 + 특성·업그레이드 보너스 → 방침 배수 → (피곤이면 ×0.7) → 반올림해 정수.
- **휴식 계산 순서:** 기본값 + 특성·업그레이드 보너스 → 방침의 휴식 회복 배수 → 반올림해 정수. 지식 -2는 그대로.
- 학식은 방침과 상관없다. 이미 든든함일 때 또 먹으면 남은 시간이 새 지속 시간으로 다시 채워진다(겹쳐 쌓이지 않는다).
- 반올림은 Python `round()`다(.5는 가까운 짝수로). 예: 휴식 위주 공부 체력 -5 × 0.7 = -3.5 → -4, 휴식 위주 휴식 체력 15 × 1.5 = 22.5 → 22.
- 시험 기간 2배는 기본 지식(10 → 20)에만 적용된다. 참고서·도서관 보너스는 2배가 되지 않는다.
- 보너스·디버프 없이 방침만 적용한 행동 한 번의 결과는 아래와 같다.

| 방침 | 공부 지식 (시험 기간) | 공부 체력 | 공부 멘탈 | 휴식 체력 | 휴식 멘탈 |
|---|---|---|---|---|---|
| 공부 위주 | +18 (+36) | -9 | -14 | +15 | +20 |
| 균형 | +10 (+20) | -5 | -8 | +15 | +20 |
| 휴식 위주 | +7 (+14) | -4 | -6 | +22 | +30 |

### 디버프와 버프

| 이름 | 종류 | 붙는 조건 | 효과 |
|---|---|---|---|
| 피곤 | 디버프 | 체력 30 미만 | 공부 지식 ×0.7 |
| 우울 | 디버프 | 멘탈 30 미만 | 지식으로 버는 연구비 ×0.7 |
| 든든함 | 버프 | 학식을 먹은 뒤 30초(+보너스) | 체력 자연 감소 ×0.5 |
| 개운함 | 버프 | 쉬게 하기 뒤 20초 (다시 쉬면 처음부터) | 멘탈 자연 감소 ×0.5 (시험 기간 2도 1로) |
| 컨디션 좋음 | 버프 | 휴식 위주 방침이고 체력·멘탈 둘 다 70 이상 | 지식으로 버는 연구비 +50% (×1.5) |

- 30은 최댓값과 상관없는 고정 기준이다(빨간 막대·다크서클 기준과 같다).
- 피곤은 **공부하기 직전** 체력으로 판정한다. 우울·컨디션 좋음은 **연구비를 쌓는 순간**(행동·이벤트 효과가 적용된 뒤)의 게이지로 판정한다.
- 우울·컨디션 좋음은 지식으로 버는 연구비에만 곱한다. 졸업 보너스와 장학금에는 곱하지 않는다.
- 든든함 시간은 게임 시간(경과 시간)으로 잰다. 대화창이 떠 있는 동안 멈추고, 대학원 진학 때 그대로 이어지며, 새 판에서 없어진다.
- 상태 패널 위쪽에 지금 붙어 있는 디버프·버프가 아이콘 배지로 보이고, 마우스를 올리면 효과 툴팁이 뜬다(6절).

### 진급과 졸업

| 단계 | 누적 지식 (이상) |
|---|---|
| 2학년 | 400 |
| 3학년 | 900 |
| 4학년 | 1500 |
| 졸업 | 2200 |

- 지식이 목표 **이상**이 되는 순간(자동 행동·이벤트·선택 직후) 진급한다. 399는 1학년, 400은 2학년이다.
- 한 번에 여러 목표를 넘으면 그만큼 오른다. 4학년에서 2200 이상이 되면 바로 졸업이다.
- 학년은 내려가지 않는다. 휴식으로 지식이 목표 아래로 줄어도 그대로다.
- 진급해도 캐릭터 크기는 그대로고(3학년부터 안경), 장소 배경이 바뀌고, "n학년 진급!" 알림이 2초 뜬다.
- 체력·멘탈이 0이 된 순간 졸업 목표도 넘었으면 **휴학이 먼저**다.

### 졸업 등급과 졸업 보너스

졸업 등급은 판 시작부터 졸업까지 **걸린 게임 시간**으로 정한다. 선택지 대화창이 떠 있던 시간은 게임 시간이 멈추므로 빠진다.

| 등급 | 졸업까지 걸린 시간 | 졸업 보너스 (연구비) |
|---|---|---|
| 수석 졸업 | 290초 이하 | +200 |
| 무사 졸업 | 290초 초과 720초 이하 | +100 |
| 아슬아슬 졸업 | 720초 초과 | +50 |

> 290초 / 720초는 밸런스 B안(2026-11-24, 10절)으로 정했다. 업그레이드 없는 첫 판은 무사, 업그레이드를 모아 4번째 판쯤 첫 수석이 나온다(`config.py`의 `TOP_GRADUATE_SECONDS`, `NORMAL_GRADUATE_SECONDS`).

- 졸업 보너스는 명성 배수(1 + 0.1 × 명성)를 곱하고 내림한다. 휴학·대학원 수료는 보너스가 없다.
- 엔딩 화면에 걸린 시간("졸업까지 3분 9초")과 누적 지식, 졸업 보너스가 보인다.
- 경계: 290초는 수석, 290.0001초는 무사, 720초는 무사, 720.0001초는 아슬아슬이다.

### 엔딩 정리

| 엔딩 | 조건 | 엔딩 화면에서 |
|---|---|---|
| 휴학 | 1~4학년에서 체력 또는 멘탈이 0 | R: 다시 하기 (명성 변화 없음) |
| 수석 / 무사 / 아슬아슬 졸업 | 4학년에서 누적 지식 2200 이상 | R: 환생 (명성 +1), C: 대학원 진학 |
| 대학원 n년차 수료 | 대학원에서 체력 또는 멘탈이 0 | R: 환생 (명성 +1) |

모든 엔딩 화면에서 U로 업그레이드 패널을 열 수 있다. 엔딩이 나면 최고 기록과 연구비가 저장된다(3절).

### 60초 주기 (계절·낮밤·시험 기간·이벤트 시계)

판 시작부터 흐른 게임 시간을 60초 주기로 나눈다. 주기는 학년과 상관없이 반복되고, 대학원에 들어가도 이어서 흐른다.

| 주기 안 시간 | 계절 | 시험 기간 |
|---|---|---|
| 0~15초 | 봄 | 아님 |
| 15~30초 | 여름 | 아님 |
| 30~45초 | 가을 | 아님 |
| 45~60초 | 겨울 | **시험 기간** |

- **주기 번호** = 경과 시간 // 60 + 1 (0~60초 1번, 60~120초 2번 …). **주기 안 시간** = 경과 시간 % 60.
- **시험 기간**(주기 안 45초 이상): 상단에 노란 배너 "시험 기간! 공부 효과 2배, 멘탈 감소 2배"가 뜬다. 공부 기본 지식이 +20이 되고, 멘탈 자연 감소가 -2가 된다. 공부의 체력 -5, 멘탈 -8은 그대로다.
- **낮·저녁·밤:** 계절 15초 안에서 0~9초 낮, 9~12초 저녁, 12~15초 밤이다.
- 경계: 14.99초 봄 → 15초 여름, 44.99초 가을(시험 아님) → 45초 겨울(시험 기간), 59.99초 시험 기간 → 60초 다음 주기 봄(시험 아님).
- 랜덤 이벤트의 최소 보장·최대 횟수도 주기마다 센다(4절).

## 3. 성장: 연구비·업그레이드·환생·대학원

### 연구비와 명성

- **연구비:** 지식이 **오를 때마다** 오른 양 × (1 + 0.1 × 명성) × 대학원 배수 × 컨디션 배수 × 연구 과제 배수(1 + 0.1 × 연구 과제 수주 Lv)만큼(내림) 쌓인다. 컨디션 배수는 우울이면 0.7, 컨디션 좋음이면 1.5, 아니면 1.0이다(2절 "디버프와 버프"). 자동 행동·자동형 이벤트·선택지 모두 같다. 지식이 줄어도 연구비는 줄지 않는다.
- **졸업 보너스:** 수석 +200, 무사 +100, 아슬아슬 +50 (× 명성 배수, 내림). 휴학·대학원 수료면 보너스는 없지만 그때까지 번 연구비는 남는다.
- **장학금:** 장학금 제도 업그레이드를 사면 자동형 이벤트 "장학금을 받았다"가 생긴다. 연구비 +30 × 지금 학년(대학원은 4)을 그대로 준다. 명성·대학원 배수는 곱하지 않는다.
- **명성:** 졸업한 판(대학원 수료 포함)에서 환생하면 +1. 연구비 획득 배수가 0.1씩 오른다.
- **명성 칭호(2026-11-24 추가, 보여 주기용):** 명성 0 시간강사, 2 조교수, 5 부교수, 10 정교수, 20 명예교수. 타이틀에 "조교수 · 명성 3 · 연구비 1200"처럼 보이고, 환생으로 칭호가 오르면 새 판 무대 오른쪽 위에 "조교수 승진!" 알림이 2초 뜬다. 업그레이드를 모두 채우는 데 환생 약 20번이 걸려 명예교수가 사실상 완주 표시다. 새 게임(N)이면 명성과 함께 시간강사로 돌아간다.
- 최고 기록·연구비·명성·업그레이드 레벨은 판이 끝날 때마다(휴학·졸업·수료), 업그레이드를 살 때, 환생할 때, 새 게임(N)을 시작할 때 `record.json`에 저장된다(형식은 9절).
- **하던 판 저장(2026-11-24):** 게임·대화창 화면에서 게임 시간 10초마다, 그리고 ESC·창 닫기로 끌 때 진행 중인 판(게이지·지식·학년·대학원 년차·경과 시간·특성·외형·연계 플래그·본 이벤트·주기별 이벤트 수·버프 남은 시간·방침·자동 행동 시계·이벤트 로그, 떠 있던 선택지 대화창)을 `record.json`의 "run"에 저장한다. 판이 끝나면(휴학·졸업·수료) 지운다. 타이틀·엔딩에서 끄면 저장하지 않는다(타이틀이면 저장된 판은 그대로).
- **이어하기와 새 게임:** 타이틀에서 Enter는 **이어하기**다. 저장된 판이 있으면 그 판을 그대로 이어서(대화창이 떠 있었으면 다시 띄움) 시작하고, 없으면 업그레이드·연구비·명성·최고 기록을 그대로 두고 새 판을 시작한다. 저장된 판이 있으면 시작 안내가 "Enter를 눌러 이어하기 (2학년, 3분 12초)"로 바뀐다(대학원이면 "대학원 n년차"). 저장된 값이 깨졌거나 맞지 않으면 무시하고 새 판으로 시작한다. N은 **새 게임**이다. 업그레이드 14종 레벨·연구비·명성을 모두 0으로 되돌리고 하던 판도 지운 뒤 `record.json`에 저장하고 새 판을 시작한다. 최고 기록(best_knowledge)은 지금까지의 최고 점수라 지우지 않는다. 잃을 진행(업그레이드·연구비·명성·하던 판)이 하나라도 있으면 타이틀에 확인 상자가 뜨고 Y로 시작, N 또는 Backspace로 취소한다(ESC는 어디서나 게임 종료라 취소 키로 쓰지 않는다). 셋 다 0이면 확인 없이 바로 시작한다.

### 환생과 대학원

4학년에서 누적 지식 2200을 채우면 졸업 엔딩 화면에서 둘 중 하나를 고른다.

- **R: 환생** — 명성 +1, 새 신입생으로 처음부터 시작한다. 업그레이드와 연구비는 그대로다. 게이지·지식·특성·외형·이벤트 기록·방침은 처음으로 돌아간다.
- **C: 대학원 진학** — 같은 제자가 게이지·지식·특성·외형·연계 플래그·든든함 남은 시간을 그대로 가지고 "대학원 1년차"로 계속한다. 경과 시간(60초 주기 시계)도 졸업한 순간부터 이어서 흐른다. 자동 행동 시계는 그때의 자동 행동 간격(기본 2초, 시간 관리 업그레이드로 줄어듦)부터 다시 잰다.

대학원 규칙은 아래와 같다. 대학원은 끝없이 이어진다.

| 항목 | 규칙 |
|---|---|
| 년차 목표 | n년차 → n+1년차 목표 = 2200 + (800 + 200 × (k − 1))을 k = 1..n까지 더한 값. 누적 지식 3000이면 2년차, 4000이면 3년차, 5200이면 4년차, 6600이면 5년차 … (해마다 800, 1000, 1200 … 더 모아야 한다) |
| 자연 감소 | ×(1 + 1.0n + 2.5c). n = 대학원 년차, c = 대학원에 들어간 뒤 다 채운 60초 주기 수(진학 시각부터 60초마다 1씩 오름). 건강 관리 배수와 곱한다 |
| 연구비 | 연구비 ×(1 + **1.0**n). 2년차면 3배다 |
| 이벤트 | 선택지형은 나오지 않고 자동형만 나온다. 최소 보장·최대 횟수 규칙은 같다 |
| 화면 | 정보바 "대학원 n년차", 목표 "다음 년차까지 지식 n", 년차가 오르면 "대학원 n년차!" 알림. 장소는 연구실, 제자는 반지름 60에 안경 |
| 끝 | 체력 또는 멘탈이 0이면 "대학원 n년차 수료" 엔딩. R로 환생(명성 +1) |

- 학부에는 시간 제한이 없고, **대학원에서만 시간 압박**이 있다. 오래 버틸수록 c가 커져 빨리 지친다.
- 예: 1년차에 들어가자마자 자연 감소는 ×2.0, 진학 60초 뒤 ×4.5, 120초 뒤 ×7.0이다(개운함을 넣으며 c 항 1.5 → 2.5).

## 4. 랜덤 이벤트와 성장 요소

매 판이 다르게 흘러가도록 대학 생활 이벤트가 일어난다. 선택에 따라 특성·외형·연계 이벤트가 남는다.

### 발생 규칙

- 자동 행동이 **실제로 실행된 직후**에만 판정한다. 그 행동으로 휴학·졸업하면 이벤트는 뜨지 않는다.
- **최대:** 60초 주기마다 5회.
- **최소 보장:** 주기 안 0~45초를 11.25초씩 4구간으로 나눈다. 구간 k(1~4)가 끝난 뒤(주기 안 경과 ≥ 11.25 × k초) 그 주기 이벤트 수가 k보다 적으면, 다음 자동 행동 때 확률과 상관없이 이벤트가 뜬다. 그래서 주기마다 최소 4회가 된다.
- **확률:** 보장이 아니면 25%다(행운 부적 레벨마다 +5%p, 최대 40%). 단, 직전 이벤트 이후 게임 시간이 **8초 이상** 지나야 한다(최소 간격). 최소 간격은 주기·학년이 바뀌어도 이어서 센다. 보장 이벤트는 최소 간격의 예외다. 새 판에서는 초기화된다.
- **고르기:** 지금 나올 수 있는 선택지형(학년 조건·연계 조건을 만족하고 이번 판에 아직 안 나온 것)과 자동형을 모은다. 선택지형 후보가 있으면 50%는 선택지형, 50%는 자동형이다. 없으면 자동형이다. 같은 종류 안에서는 고르게 뽑는다.
- 선택지형의 학년 조건은 **지금 학년**(지식으로 오른 학년)으로 판단한다. 같은 선택지형은 한 판에 한 번만 나온다. 자동형은 반복될 수 있다.
- 이벤트 효과도 게이지 범위 규칙을 지키고, 효과 직후 진급·졸업과 휴학을 판정한다(휴학이 먼저).

**자동형(작은 사건):** 게임은 멈추지 않는다. 무대 왼쪽 위에 알림이 2초 뜨고 효과가 바로 적용된다. 효과 합이 0 이상이면 좋은 일(민트색, 하트), 음수면 나쁜 일(분홍색, 느낌표)로 보인다.

**선택지형(큰 사건):** 게임이 멈춘다(경과 시간·게이지·자동 행동 시계 정지). 대화창에 제목, 상황 한 줄, 선택 버튼 2개와 효과 미리보기가 나온다. 키 1·2 또는 클릭으로 고르면 결과가 적용되고 게임이 다시 흐른다.

- 대화창이 뜬 뒤 0.3초 동안은 선택 입력을 받지 않는다(방침 키를 누르다가 그대로 선택되는 것을 막는다).
- 대화창이 떠 있는 동안 방침 키·버튼과 업그레이드 패널은 동작하지 않는다(패널은 숨김). ESC 종료는 된다.

"학년"은 표에 적힌 학년에서만 나온다는 뜻이다(2~4는 2·3·4학년 모두 가능).

### 특성

얻으면 그 판 끝까지(대학원 포함) 유지되고, 새 판에서 초기화된다. 상태 패널 아래쪽에 얻은 순서대로 작은 배지(2열)로 보이고, 마우스를 올리면 효과 툴팁이 뜬다(6절).

| 특성 | 효과 |
|---|---|
| 체력 단련 | 학식 먹이기 든든함 지속 +10초 (30초 → 40초) |
| 음악 힐링 | 쉬게 하기 멘탈 +20 → +25 |
| 카페인 | 공부시키기 체력 -5 → -3 |
| 연애 중 | 쉬게 하기 체력 +15 → +20 |
| 아침형 인간 | 쉬게 하기 체력 +15 → +18, 멘탈 +20 → +23 |
| 스터디 그룹 | 공부시키기 지식 +10 → +12 (시험 기간 2배 없음, 방침 배수 전에 더함) |
| 자취 요리 | 학식 먹이기 든든함 지속 +5초 (30초 → 35초) |
| 명상 | 공부시키기 멘탈 -8 → -6 |

특성은 최대 8개다. 배지는 2열 4줄(y 344부터, 간격 4)로 놓아 8개가 모두 상태 패널 안에 들어간다(이를 위해 멘탈 라벨·막대를 y 280·312로 40 올렸다).

### 외형

기타(얼굴 뒤), 헬스 머리띠(이마), 커피잔(얼굴 오른쪽 아래), 하트 머리핀(머리 왼쪽), 선글라스(머리 위) 5가지다. 얻으면 그 판 끝까지 제자에게 도트로 붙어 있고, 학년마다 얼굴과 함께 커진다. 안경·다크서클·표정과 서로 겹치지 않는다.

### 이벤트 로그

게임 화면에서 **L키**를 누르면 상태 패널 자리(업그레이드 패널과 같은 자리 12~268, 116~468)에 이벤트 로그 패널이 열리고, 다시 누르면 닫힌다. 게임은 계속 흐르고 방침 키도 그대로 된다. 업그레이드 패널과는 하나만 열린다(U를 누르거나 [업그레이드 U]를 누르면 로그가 닫히고, L을 누르면 업그레이드 패널이 닫힌다). 타이틀·대화창·엔딩에서는 L이 동작하지 않는다. 로그가 열려 있는 동안 상태·특성 배지 툴팁은 뜨지 않는다.

- **기록:** 자동형은 이벤트가 일어날 때, 선택지형은 선택지를 고를 때 한 항목이 쌓인다. 이번 판(대학원 포함)의 최근 30개를 기억하고, 새 판(Enter·N·다시 하기·환생)에서 비운다.
- **모양:** 머리 줄 "이벤트 로그"와 오른쪽 "L 닫기", 그 아래 항목 상자(232×40, 간격 42) 7개까지 새것부터. 첫 줄 "1분 10초 · 조별과제 무임승차자", 둘째 줄은 결과 — 자동형 "체력 +15"(장학금 "연구비 +60"), 선택지형 "혼자 다 한다 → 지식 +20 · 체력 -15 · 멘탈 -10"(특성·외형은 "특성: 명상", "외형: 기타"). 상자보다 긴 글자는 뒤를 잘라 "…"를 붙인다. 아직 없으면 "아직 이벤트가 없어요".
- 게임 화면 오른쪽 아래(경과 시간 밑, y 577)에 작은 글씨로 "L: 이벤트 로그" 안내가 있다.

**업그레이드 툴팁:** 업그레이드 패널이 열려 있을 때 항목 줄에 마우스를 올리면(게임·엔딩 화면) 그 줄의 설명 상자를 패널 오른쪽(무대 위, x 276부터)에 그 줄 높이에 맞춰 띄운다. 마우스를 올렸을 때만 뜨므로 패널만 열어 두면 무대·엔딩 글자를 가리지 않는다. 키보드(↑↓)로 고른 줄은 패널 바닥 줄 "효과: …"로 본다. 위아래로는 무대 범위(y 116~460) 안으로 밀어 넣는다. 줄:

1. "이름  Lv 지금/최대" (예: "참고서  Lv 2/5")
2. "지금: 효과" — 효과 = 레벨 × 레벨당 효과를 config 값으로 계산 (예: "지금: 공부 지식 +4"). 0레벨이면 "지금: 아직 없음"
3. "다음: 효과" (예: "다음: 공부 지식 +6"), 최고 레벨이면 "다음: 최고 레벨"
4. "무대: …" 장식 설명 (예: "무대: 책장이 생겨요 (책 = Lv)")
5. (방어형 5종 체력 증진·멘탈 관리·건강 관리·카페·헬스장) "공부 위주·대학원에서 쓸모가 커요", (행운 부적) "이벤트가 자주 떠요" 한 줄 — 수치는 그대로
6. "가격: 연구비 n" 또는 "가격: MAX"
7. 연구비가 가격보다 적으면 빨간 글씨 "연구비가 모자라요"

효과는 방침 배수를 곱하지 않은 기본 효과다. 패널 바닥 줄 "효과: …"(레벨당 효과)는 그대로 둔다(키보드로 고를 때도 보이는 짧은 요약).

**상태 배지 툴팁:** 게임 화면에서 업그레이드 패널이 닫혀 있을 때 상태 배지에 마우스를 올리면 그 배지 높이에 맞춰 상태 패널 오른쪽에 한 줄 설명이 뜬다.

| 상태 | 아이콘 | 툴팁 예 |
|---|---|---|
| 피곤 | Zz | "피곤: 체력 30 미만 — 공부 지식 ×0.7" |
| 우울 | 비구름 | "우울: 멘탈 30 미만 — 버는 연구비 ×0.7" |
| 든든함 | 김 나는 밥그릇 | "든든함: 남은 시간 12초 — 체력 감소 ×0.5" (남은 시간은 올림한 초) |
| 개운함 | 물방울 | "개운함: 남은 시간 13초 — 멘탈 감소 ×0.5" |
| 컨디션 좋음 | 반짝 별 | "컨디션 좋음: 휴식 위주, 체력·멘탈 70 이상 — 버는 연구비 ×1.5" |

아이콘은 8×6칸(칸 2픽셀) 도트로 배지 안 왼쪽에, 이름은 그 오른쪽에 쓴다.

**특성 배지 툴팁:** 상태 배지 툴팁과 같은 조건(게임 화면, 업그레이드 패널이 닫혀 있을 때)에서 특성 배지에 마우스를 올리면, 그 배지 높이에 맞춰 상태 패널 오른쪽에 한 줄 설명이 뜬다(무대 아래 끝 안으로 밀어 넣음). 글자는 `TRAIT_BONUSES` 값으로 채운다.

## 7. 기능 목록

총 24개 기능이다. 1~10번은 필수 기능(원래 기획의 필수 기능을 방치형에 맞게 바꾼 것), 11~24번은 추가 기능이다.

### 필수 기능

1. 자동 행동 (자동, 2초마다): 기준 미만이면 휴식, 든든함이 없으면 학식, 아니면 공부를 스스로 실행
2. 일과표 방침 (1·2·3키 또는 방침 버튼): 공부 위주 / 균형 / 휴식 위주로 회복 기준·공부 배수·휴식 회복 배수가 바뀜
3. 행동 효과 (자동 행동 때): 학식 든든함 30초, 휴식 체력 +15·멘탈 +20·지식 -2, 공부 지식 +10·체력 -5·멘탈 -8
4. 자동 행동 진행 막대 (자동): 다음 자동 행동까지 남은 시간을 방침 버튼 아래 막대로 표시
5. 게이지 자연 감소 (자동, 1초마다): 체력·멘탈 -1 (든든함이면 체력 -0.5)
6. 게이지 막대 표시 (자동): 체력·멘탈은 막대와 "지금/최대"로, 30 미만이면 빨간색 / 지식은 정보바에 숫자
7. 표정 변화 (자동): 멘탈에 따라 입 모양, 체력 30 미만이면 다크서클
8. 학점 진급과 캐릭터 성장 (누적 지식이 400/900/1500 이상): 학년이 오르고 캐릭터가 커짐, 3학년부터 안경, 진급 알림
9. 휴학 엔딩 (체력 또는 멘탈 0): 즉시 엔딩 화면으로 전환
10. 화면 전환 (Enter / N / R / C / ESC): 타이틀 → 게임 → 엔딩, 이어하기·새 게임(확인 Y, 취소 N·Backspace)·다시 하기·환생·대학원, 종료

### 추가 기능

11. 시험 기간 (60초 주기의 45~60초): 노란 배너, 공부 지식 +20, 멘탈 자연 감소 -2
12. 졸업 엔딩 3종 (4학년에서 누적 지식 2200 이상): 걸린 시간 290초 이하 수석 / 720초 이하 무사 / 초과 아슬아슬, 학사모, 졸업 보너스
13. 기록 저장 (판 끝·업그레이드 구매·환생·새 게임 때): 최고 기록·연구비·명성·업그레이드 레벨을 record.json에 저장, 타이틀에 표시. 타이틀 N(새 게임)은 최고 기록만 남기고 나머지를 0으로 되돌림
14. 도트 그래픽과 화면 연출 E1~E6 (자동): 호버·눌림, 파티클, 수치 팝업, 부드러운 게이지, 점프·숨쉬기, 안내 깜빡임
15. 랜덤 이벤트 (자동 행동 직후): 자동형 6종(공모전 입상 포함, +장학금)과 선택지형 14종, 주기당 최소 4회·최대 5회, 최소 간격 8초
16. 특성·외형·연계 이벤트 (선택지 결과): 특성 8종 보정(배지에 마우스를 올리면 효과 툴팁), 외형 5종 도트, 연계 이벤트 3종
17. 연구비와 명성 (지식이 오를 때, 졸업·환생 때): 연구비 = 오른 지식 × 명성·대학원·컨디션 배수, 졸업 보너스, 명성 +1
18. 업그레이드 14종 (U키 또는 버튼, ↑↓·Enter·클릭): 가격 기본 × 2.0^레벨, 효과는 바로 적용되고 다음 판에도 유지. 항목 툴팁(지금·다음 효과, 무대 장식, 가격)
19. 환생 (졸업·수료 엔딩에서 R): 명성 +1, 새 신입생으로 처음부터, 업그레이드·연구비 유지
20. 대학원 진학 (졸업 엔딩에서 C): 같은 제자로 끝없이 진행, 년차 목표 3000/4000/5200 …, 자연 감소 ×(1 + 1.0n + 2.5c), 연구비 ×(1 + 1.0n), 수료 엔딩
21. 무대 배경 4겹 (학년·주기·행동·업그레이드에 따라 자동): 장소, 하늘과 계절, 행동 소품, 시설과 업그레이드 장식 14종
22. 목표 진행 막대와 경과 시간 (자동): 다음 목표까지 남은 지식과 진행률, "경과 m분 s초"
23. 디버프와 버프 (자동): 피곤(체력 30 미만, 공부 지식 ×0.7), 우울(멘탈 30 미만, 연구비 ×0.7), 든든함(학식, 체력 감소 ×0.5), 개운함(휴식, 멘탈 감소 ×0.5), 컨디션 좋음(휴식 위주, 연구비 +50%), 상태 패널 아이콘 배지와 효과 툴팁
24. 이벤트 로그 (L키, 게임 화면): 이번 판 이벤트를 새것부터 7개까지 "시간 · 이름"과 결과로 보여 줌

## 9. 사용 기술과 프로그램 구조

| 구분 | 사용 기술 | 용도 |
|---|---|---|
| 언어 | Python 3.12 | 게임 전체 구현 |
| 라이브러리 | pygame 2.6 (2.6.1) | 창, 도형 그리기, 입력, 시계 |
| 표준 라이브러리 | json, sys, os, random | 기록 저장, 종료, 파일 경로, 랜덤 이벤트 |
| 폰트 | 맑은 고딕 (`pygame.font.SysFont("malgungothic", 크기)`) | 한글 출력 (Windows 기본 폰트, 별도 파일 불필요) |
| 테스트 (개발 도구) | pytest | 화면 없는 자동 검수 (`SDL_VIDEODRIVER=dummy`) |
| 빌드 (개발 도구) | PyInstaller | Windows 실행 파일(.exe) 생성 |
| 버전 관리 | Git, GitHub | 코드 관리, PR, 과제 제출 |
| 실행 환경 | Windows 10/11 | - |

- random은 랜덤 이벤트에만 쓴다. 게임 객체마다 `random.Random(시드)` 인스턴스를 하나 두고 그것만 쓴다(테스트에서 시드 고정). 파티클 같은 연출은 정해진 표를 쓴다.
- 이미지·사운드 파일은 쓰지 않는다. 모든 수치·좌표·색·문구·도트 격자는 `config.py` 상수다.

### record.json

```json
{"best_knowledge": 2216, "money": 122, "fame": 3, "upgrades": {"menu": 2, "bed": 2, "reference_book": 2, "time_management": 1, "health_care": 1, "library": 0, "cafe": 0, "gym": 0, "lucky_charm": 1, "scholarship": 0, "health_max": 1, "mental_max": 0, "self_care": 0}}
```

| 키 | 내용 |
|---|---|
| best_knowledge | 최고 기록 (지금까지 판이 끝났을 때 누적 지식 중 최고) |
| money | 연구비 |
| fame | 명성 |
| upgrades | 업그레이드 id → 레벨 (menu, bed, reference_book, time_management, health_care, library, cafe, gym, lucky_charm, scholarship, health_max, mental_max, self_care, research_grant) |
| run | (판 진행 중일 때만) 하던 판: health, mental, knowledge, elapsed, decay_timer, grade, grad_year, graduation_time, grad_entry_time, last_event_time, full_until, refresh_until, traits, looks, flags, seen_events, event_counts, policy, auto_timer, event_log, event |

- 저장 위치: exe로 실행하면 exe 파일이 있는 폴더(`sys.executable`), Python으로 실행하면 `main.py`가 있는 폴더.
- 예전 형식(`{"best_knowledge": n}`)도 읽는다. 없는 값(예: 업그레이드 10종 시절 파일의 health_max·mental_max·self_care), 0 이상의 정수가 아닌 값, 최대 레벨을 넘는 레벨은 0으로 본다. 모르는 업그레이드 id는 무시한다. 파일이 없거나 깨져 있어도 멈추지 않고 0으로 시작한다.
- 저장에 실패해도(폴더 권한 없음 등) 게임은 계속된다.

## 10. 밸런스

지금 수치는 2026-11-24 밸런스 시뮬레이션 뒤 사용자 승인(**B안**)으로 정했다. 진급 기준(400 / 900 / 1500 / 2200)과 회복·디버프 규칙은 M단위 그대로다.

| 항목 | 값 | 정한 이유 |
|---|---|---|
| 진급·졸업 목표 | 400 / 900 / 1500 / 2200 | 업그레이드 없는 첫 판 졸업이 약 6~11분 |
| 수석 졸업 | 290초 이하 | 업그레이드 없는 공부 위주 첫 판에서 수석이 거의 나오지 않게(특성·개운함 추가로 학부가 빨라져 330 → 290초) |
| 무사 졸업 | 720초 이하 | 업그레이드 없는 첫 판은 균형·휴식 위주 모두 무사 |
| 공부 위주 | 회복 기준 25, 공부 지식 ×1.8, 소모 ×1.8 | 가장 빠르지만 위험하다: 우울이 잦고 업그레이드 없이 10~30% 휴학 |
| 휴식 위주 컨디션 좋음 | 연구비 ×1.5 | 가장 느리고 안전한 대신 균형보다 시간당 연구비가 많게(약 +12%) |
| 업그레이드 가격 | 기본 가격 × 2.0^레벨 (14종 전부 108,090) | 환생을 여러 번 해서 약 70분에 모두 채우게 |
| 대학원 자연 감소 | ×(1 + 1.0n + 2.5c) | 업그레이드를 모두 사도 대학원이 약 30분 안에 끝나게 (개운함 추가로 1.5c → 2.5c: 시드 0 기준 업그레이드 없음 4.4분 / 중간 7.5분 / 최고 레벨 28.2분, 1.5c 그대로면 7.1 / 10.6 / 44.0분) |
| 대학원 연구비 | ×(1 + 1.0n) | 대학원에서 버틴 만큼 연구비를 많이 주게 |
